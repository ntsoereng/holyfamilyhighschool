# Google Fonts

Libre Baskerville (400, 700) is used for headings; Manrope (400–800) is used for body text and controls. Files were downloaded from the Google Fonts CSS API and are served locally, with font-display: swap. The associated SIL Open Font Licences are included in this directory.

Sources: https://fonts.google.com/specimen/Libre+Baskerville and https://fonts.google.com/specimen/Manrope
