# Locally served fonts

Libre Baskerville (400, 700) is used for serif headings. Rubik (variable weight 300–900, with regular body text at 400) is used for body text and interface controls across public pages and the staff workspace. Fonts are served locally with `font-display: swap`.

Rubik source: https://github.com/google/fonts/tree/main/ofl/rubik
Rubik licence: `rubik-OFL.txt` (SIL Open Font License).

Libre Baskerville source: https://fonts.google.com/specimen/Libre+Baskerville
Licence: `librebaskerville-OFL.txt`.

The previous Manrope assets and licence are retained for existing cached references; current styles use Rubik.
